#### 📄 [Document Intelligence](https://github.com/ashwinth-dharumaseelan/document-intelligence)

**Every document. Found in a second.**

An end-to-end AI system that reads invoices, contracts, court judgments, licences, IDs and letters in any format, then extracts, validates and indexes them for instant search and Q&A.

- 🧠 OCR, classification and per-type field extraction with AI Functions
- ✅ Business-rule validation: **94.5% exact field accuracy**
- 🔎 Hybrid vector search and a citing chat assistant
- ⚡ Fully automatic, from upload to searchable in ~6 minutes
